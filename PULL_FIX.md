# If Pull is blocked on Code Assist

The red warning means **local icon files** differ from GitHub.

## Fix (on phone)

1. Source Control (branch icon)
2. For each file listed (`ic_launcher.png` …):
   - Open the **⋯** menu on that file
   - Choose **Discard** / **Discard changes** / **Restore**
3. Tap **Pull** again
4. **Build → Clean** (optional)
5. **Run**

You do **not** need to Commit or Push those icon files.
